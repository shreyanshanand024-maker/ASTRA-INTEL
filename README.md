# ASTRA-INTEL

## AI-Powered Defence Document Intelligence System

ASTRA-INTEL is a document intelligence web application that analyzes PDF documents and extracts useful information through a simple dashboard.

## Features

- PDF document upload
- Text extraction using PyMuPDF
- OCR support for scanned PDF pages using Tesseract
- Document page and word count
- Automatic document summary
- Keyword extraction
- Topic detection
- Extracted text display
- FastAPI-based web dashboard

## Technology Stack

- Python
- FastAPI
- Uvicorn
- PyMuPDF
- Tesseract OCR
- HTML / CSS
